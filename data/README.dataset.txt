Synthetic dataset of black and white stones on go boards. Generated using [Unity Perception](https://blog.roboflow.com/unity-perception-synthetic-dataset-tutorial/)


### Use Case
To be able to take a picture of a go game and figure out the position of each stone in order to score the game or analyze with AI. Project inspiration stems from this blog post along with past ideas we've had for this: https://blog.roboflow.com/chess-boards/

### Classes
`blackStone`: Black go stones, `90,501` labels
`whiteStone`: White go stones, `89,963` labels
`grid`: Cross section grid of a go board, `1,000` labels
